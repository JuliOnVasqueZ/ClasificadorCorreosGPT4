GoodTech FTP Server The GoodTech FTP server is vulnerable to denial-of-service attacks. Certain commands will stop the listening threads from operating correctly. If enough commands are sent, all available sockets will be closed. For a patch: Linux-Mandrake releases patch for xpdf, Xchat and glibc According to the Linux-Mandrake alert, there is a potential race condition when using tmpnam() and fopen() in xpdf versions prior to 0.91. This exploit can be only used as root to overwrite arbitrary files if a symlink is created between the calls to tmpname() and fopen().
