According to Cerberus, this directory not only contains a number of batch files, DLLs and executables but also the binary image file for the Listener itself, which could lead to malicious users executing commands on the server with special query strings. No patch is available yet, though Cerberus recommends removing the ows-bin directory or point to a more benign directory.
