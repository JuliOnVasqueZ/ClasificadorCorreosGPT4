Any management team that aspires to be a first mover must ask itself, What race are we running: sprint or marathon? If you try to run a 100-yard sprint like a marathon, you'll be left behind. If you try to run a marathon like a 100-yard sprint, you'll keel over from exhaustion. So it is critically important to ask some questions: Are there difficult technical hurdles?
