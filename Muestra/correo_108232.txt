'Daily Change' : shows the change (increase +/decrease -) in the daily volume needed from Enron at the designated citygate delivery point relative to the supply volumes arranged previously with Enron prior to the current date. For the current gas day, the change is an intra-day change and is calculated using the previous day's volume request for the current day (e.g., If the current gas day is 3/28, then the change is computed with respect to the 3/27 request for 3/28.
