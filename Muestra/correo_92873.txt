NAS alleviates the awkward setups of parallel cabling, host bus adapters, and termination that are part and parcel of a file server implementation. Companies simply plug the system into the network and it is ready to go. Many NAS appliance vendors claim an installation takes less than an hour. Yet for all its advantages over a file server model, one drawback of NAS is that it shifts storage transactions from parallel SCSI connections to the production network.
