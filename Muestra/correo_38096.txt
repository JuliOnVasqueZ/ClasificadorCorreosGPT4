Line #1110 is expected to be back online during this week following the installation of a release valve. Sources at El Paso report that when #1110 comes back up, there will be no significant increase of capacity flowing through the South Main Line System because there is currently no market demand for the increase. The OPS corrective action order is expected to be lifted later this fall, thereby granting the system permission to return to full capacity. However, there is a possibility that El Paso will not increase capacity on the system even then. This will depend on market demand
