Sojourn search engine exposes files The Cerberus Security Team has discovered a weakness in the commercial search engine, Sojourn, that allows attackers to read any local file on the file system that they have read access to (as provided by the account the Web server is running under). As such, files such as /etc/passwd on Unix systems can be read and files such as the global.asa on Windows NT and 2000.
