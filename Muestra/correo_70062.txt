This includes the origination and changes in value for both the physical and financial sides of hedges, along with any speculative trades and floating unhedged physical positions. VaR is "Value at Risk": Enron Corp policy defines this as the maximum expected one day loss on the portfolio given a 95% statistical confidence interval. This number is currently calculated on the Caminus system using a variance covariance methodology, rather than a Monte Carlo simulation per the Enron Corp policy.
